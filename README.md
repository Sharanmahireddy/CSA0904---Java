# Smart Library Management, Book Reservation and Overdue Notification System using Java

Course: CSA09 – Programming in Java (SLOT A)

## Requirements
- JDK 17 or later
- Command Prompt / PowerShell / VS Code / IntelliJ IDEA / Eclipse

## Run
```text
javac -d out src/*.java
java -cp out Main
```

## Features mapped to the assignment
- OOP: encapsulation, data hiding, constructors, inheritance and runtime polymorphism.
- Collections: ArrayList, HashSet, HashMap, Hashtable with generics.
- Iterators: Iterator and ListIterator.
- Exceptions: built-in and custom exceptions for invalid members, duplicate reservations, unavailable books and invalid input.
- Multithreading: concurrent issue tasks, thread priorities, synchronized shared operations and wait/notifyAll in inventory.
- Menu-driven workflow: member/book registration, inventory, search/update, issue/return, reservation, notifications and reports.

## Project structure
- `src/` – Java source code
- `data/` – test cases and sample data notes
- `output/` – execution logs and generated report outputs
- `screenshots/` – execution evidence
- `docs/` – report, pseudocode and flowchart
