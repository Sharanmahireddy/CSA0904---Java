### Reflection

This assignment gave me an opportunity to apply Java programming concepts to a realistic Smart Library Management problem. My main contribution was ______________________________. I worked mainly on ______________________________ and learned how multiple Java classes can be integrated into one complete application.

A key design decision was the use of inheritance and polymorphism for different membership types. The project also helped me understand practical use of `ArrayList`, `HashSet`, `HashMap`, `Hashtable`, `Iterator` and `ListIterator`. I learned that choosing an appropriate collection depends on the required operation such as uniqueness, keyed lookup or traversal.

The most challenging part was concurrent inventory processing. Two threads may request the same last available book, so synchronization is necessary to protect shared state. I also learned how `wait()` and `notifyAll()` can coordinate threads when a book becomes available. Exception handling improved the reliability of the application by allowing invalid IDs, duplicate reservations and unavailable books to be reported without terminating the menu.

The assignment is relevant to SDG 4 because a well-managed library improves access to educational resources. It also connects to SDG 9 through software-based infrastructure and SDG 16 through reliable institutional records and accountable resource management.

With additional time, I would add persistent database storage, authentication, automatic reservation fulfilment, a web/mobile interface and real email/SMS notifications. These improvements would make the prototype closer to a production system.

Overall, I contributed to attaining CO1 through OOP, inheritance and polymorphism, CO2 through collections, generics and iterators, and CO3 through exception handling and multithreading. The main learning I gained was how individual Java concepts combine to solve a complete software problem with correctness and concurrency requirements.
