# Assignment Deliverables Checklist

Based on the supplied CSA09 assignment question and Common Course Assignment Format.

- [x] Problem statement and problem formulation
- [x] Objective and expected outcomes
- [x] Requirements, constraints and assumptions
- [x] Application of relevant course knowledge/concepts
- [x] Design/proposed solution/methodology
- [x] Algorithm/pseudocode
- [x] Flowchart
- [x] Implementation/source code
- [x] Environment/tools used
- [x] Test cases with expected/actual results
- [x] Execution screenshots/outputs
- [x] Results and validation
- [x] Analysis, comparison, trade-offs and justification
- [x] Broader considerations / SDG relevance
- [x] Conclusion, limitations and possible improvements
- [ ] Individual contribution of group members – fill actual team details
- [x] References
- [x] One-page individual reflection template
- [x] GitHub upload guide

## Important student actions before final submission
1. Fill Department/Programme/Batch/Faculty/date fields as applicable.
2. Replace the contribution table placeholders with actual registration numbers, names, responsibilities and percentages.
3. Make one reflection copy per group member and personalize it.
4. Run the program on the team's own computer and, if required by the faculty, capture fresh screenshots from that environment.
5. Upload the complete project to GitHub and submit the repository link in Google Classroom.
